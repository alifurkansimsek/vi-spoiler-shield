How to update

Update in one click

The extension downloads the new version, writes it into its own folder and restarts.

Or update by hand

Browsers do not update extensions loaded from a folder on their own.

  1. Download the zip

    The new version's zip downloads in one click.

  2. Extract the zip

    Inside is a folder called vi-spoiler-shield.

  3. Copy the files over the old folder

    Copy everything inside the new folder into the folder you loaded the extension from.

  4. Reload the extension

    Press the reload icon on the extensions page.

Don't remove the extension and load the new folder separately.
